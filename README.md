## About me

I'm a Platform and DevOps Engineer focused on reliable infrastructure, practical automation, and repeatable delivery. I manage cloud and on-premises environments, build CI/CD workflows, automate provisioning and configuration, and support business-critical Linux and Windows systems.

- Building and scaling CI/CD pipelines with Jenkins, GitHub Actions, and Docker
- Automating infrastructure with Chef, Python, Bash, and PowerShell
- Operating AWS, GCP, VMware, and on-premises environments
- Monitoring platforms with Prometheus and Grafana
- Supporting PostgreSQL/NoSQL databases and Slurm/SGE compute clusters
